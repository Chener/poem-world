# duino-1 固定打磨 prompt（循环中不修改）

## 角色
你是 builder。目标：把里尔克《杜伊诺哀歌》第一首（见 `POEM.md`）变成一个可以走进去的夜色世界，
让读者在漫游中遭遇这首诗，而不是"读到"这首诗。

## 每轮只做一件事（Ralph 式）
1. 读当前 `index.html`、`POEM.md`、`log.jsonl`。
2. 从 `log.jsonl` 最近一行的 `biggest_gap` 里取**一个**最大缺口。
3. 只修那一个缺口。不重写整个世界，不做 3A 级画面对标，不引入任何依赖或构建步骤。
4. 固定 6 机位截图到 `shots/N/`。
5. 交给一个**没有看过 builder 任何解释**的 critic 子代理（Gauntlet 式独立评审）：
   只给它《POEM.md》、意象对照表和 6 张截图，问两个问题——
   - 像不像这首诗？
   - 当前最大的缺口是什么（只说一个）？
6. 写一行 `log.jsonl`，快照到 `versions/N/index.html`。

## 硬约束
- 零依赖、零构建：`index.html` 双击能开，GitHub Pages 静态托管即可。
- 全部手写 Canvas 2D / WebGL，不引 three.js、不引 npm。
- 键盘 WASD + 鼠标转视角；触控摇杆 + 拖拽转视角。两套都必须能走。
- 右栏时间线读 `log.jsonl`，可折叠；`file://` 直开时 fetch 失败要优雅降级。
- 页脚必须标注：loop 机制 / harness / 模型 / 推理强度 / 轮数与停止原因。

## 意象对照表（critic 用）
| 诗中意象 | 世界中应出现的东西 |
|---|---|
| 夜 · 满载宇宙的风 | 夜空、星尘被风推动、面部被"啃食"的风声感 |
| 天使的序列（Engel Ordnungen） | 远处排成序列的巨大光体，靠近即压迫，不可抵达 |
| 城堡（Duino） | 悬崖上的城堡剪影，是世界的重心 |
| 山坡上的树 | 唯一可以每天重看的、具体而温柔的锚点 |
| 被抛下的恋人 | 一扇敞开的窗，窗里有小提琴的声音 / 光 |
| 早逝者 | 被丢开的名字，像摔坏的玩具散在地上 |
| 空房间与空虚 | 一间没有人的房间；把空虚抛出去，鸟群感到空气被拓宽 |

## 停止条件
10 轮 / critic 连续两轮"我们赢" / `log.jsonl` 出现 STOP / 距周限刷新不足 1 小时。
