# chunjiang 固定打磨 prompt（循环中不修改）

## 角色
你是 builder。把张若虚《春江花月夜》（见 `POEM.md`）变成一个可以走进去的春夜江上世界：
读者在漫游中遇见这首诗，而不是"读到"它。

## 每轮只做一件事（Ralph 式）
1. 读当前 `index.html`、`POEM.md`、`log.jsonl`。
2. 取 `log.jsonl` 最近一行的 `gap`，只修**那一个**缺口。
3. 不重写整个世界，不引入构建步骤，不做 3A 画面对标。
4. 拍固定 6 机位（`?shot=1..6`，时钟冻结在 `FROZEN_T`），存 `shots/N/`。
5. 交给一个**没有看过 builder 任何解释**的 critic 子代理（Gauntlet 式独立评审）：
   只给它 `POEM.md`、下面的意象对照表和 6 张截图，要它回答"像不像 / 最大缺口 / 0-10 分"。
6. 追加一行 `log.jsonl`（含 `score`），跑 `sh ../shared/mklog.sh chunjiang`，快照到 `versions/N/`。

## 硬约束
- 零依赖、零构建：`index.html` 双击能开，GitHub Pages 静态托管即可；本世界的渲染全部手写 Canvas 2D。
- 键盘 WASD + 鼠标拖拽转视角；触控摇杆。两套都必须能走。
- 右栏时间线用 `../shared/timeline.js` 读 `log.jsonl`，`file://` 下回落到 `log.js`。
- 页脚必须标注：loop 机制 / harness / 模型 / 推理强度 / 轮数与停止原因。
- 只做春夜江上的静美意象。不渲染死亡、伤害、血腥一类画面。

## 意象对照表（critic 用）
| 诗中意象 | 世界中应出现的东西 |
|---|---|
| 春江潮水连海平 | 一片与天相接的江面，潮水缓缓推来 |
| 海上明月共潮生 | 一轮从水天之际升起的大月亮 |
| 滟滟随波千万里 | 月光在波上碎成一条通向你的路 |
| 江流宛转绕芳甸 | 江水绕过一片芳甸，水纹是弯的不是直的 |
| 月照花林皆似霰 | 花林在月下白得像霰（细雪），不是绿树 |
| 汀上白沙看不见 | 你脚下的白沙汀，白到几乎分不出边界 |
| 江天一色无纤尘 | 天与水同一个颜色，只有一轮孤月 |
| 谁家今夜扁舟子 | 江上一叶慢慢漂过的扁舟 |
| 何处相思明月楼 | 对岸一座楼台，只亮一扇窗 |
| 落月摇情满江树 | 月落时，满江的树在水里晃 |
